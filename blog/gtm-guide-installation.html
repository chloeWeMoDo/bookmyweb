GTM : guide d'installation

Publie le 15 aout 2025 - Lecture 8 min

Google Tag Manager est l'outil central pour gerer tous vos tags marketing sans toucher au code source. GA4, pixels publicitaires, outils de heatmap : tout passe par GTM. Audit Analytics de Marc Lefevre en fait un pilier de sa methodologie.

Installation du conteneur

Creez un compte et un conteneur sur tagmanager.google.com. Collez le snippet JavaScript dans le head de chaque page et le snippet noscript juste apres l'ouverture du body. Verifiez l'installation avec le mode Preview de GTM.

Configurer GA4 via GTM

Creez une balise "Google Analytics : Configuration GA4" avec votre ID de mesure. Declenchez-la sur "All Pages". Publiez le conteneur. Verifiez en temps reel dans GA4 que les donnees arrivent. C'est la base de tout votre tracking.

Les declencheurs essentiels

Page View pour le chargement, Click pour les interactions, Scroll Depth pour l'engagement, Form Submission pour les conversions et Timer pour le temps passe. Ces cinq declencheurs couvrent 90 % des besoins de tracking courants.
